# Game
# 🏚️ RUINED HOUSE HUNTER

> *Four days ago, the street stopped answering.*

A browser-based first-person horror shooter built entirely in **Three.js** — no game engine, no pre-made assets, no shortcuts. Every wall, weapon, monster, and gunshot in this game is generated by code.

---

## 🎮 Play It

Open `index.html` in any modern browser. No install, no build step required for the standalone version. Desktop or mobile — touch controls included.

---

## 🔥 What's Inside

### 🧠 Enemies That Actually Hunt You
- **Real A\* pathfinding** — enemies navigate the maze's actual corridors instead of beelining through walls
- **Memory & search behavior** — lose sight of you, and they'll stalk your last known position for several seconds before giving up
- **Coordinated flanking** — swarm enemies spread out instead of funneling single-file at you
- **Cover-seeking shooters** — they duck behind walls after firing, then peek back out
- **5 distinct enemy behaviors per level**: turret, line, rush, swarm, and normal — each demanding a different approach

### 🔫 Weapons With Real Weight
- **4 weapons**, all unlimited ammo: Pistol · Shotgun · Sniper Rifle · Automatic Rifle
- **Per-weapon recoil** — vertical kick *and* horizontal spray pattern, each gun recovers at its own speed (light pistol vs. heavy sniper)
- **Full reload animation** — the gun actually dips and tilts, synced to real reload timing
- **Muzzle flash geometry** — not just a light, an actual flash shape, randomized every shot
- **Hit markers** — visual + audio confirmation on every hit, distinct feedback on kills

### 🌍 A World Built From Nothing But Code
- **5 zones**: a ruined house, a dead city street, a burned church, an abandoned warehouse, a flooded sewer
- **Procedural everything** — brick courses, cracked asphalt, brushed gunmetal, wind-swept grass, a starfield that actually follows you
- **Dynamic weather & day/night cycle**
- **Minimap** with live checkpoint tracking
- **A real story**, told through collectible notes — piece together what actually happened on this street

### 🔊 Audio Generated From Scratch
- Every gunshot, footstep, and reload click is synthesized — layered noise, real DSP filtering, procedural transients
- **Drop-in real audio support**: place files in `sfx/` and the game automatically uses them instead of the synthesized versions — zero code changes needed

## 🛠️ Tech Stack

- **Three.js r128** — rendering, all geometry procedurally generated
- **Web Audio API** — full DSP synthesis engine (no audio libraries)
- **Vanilla JS** — no framework, no dependencies beyond Three.js
- **UnrealBloomPass + custom shader** — bloom, film grain, vignette, chromatic aberration
- ACES Filmic tone mapping, sRGB color pipeline, dynamic exposure

For the modular project version (Vite-based, ready for real asset pipelines):
```bash
npm install
npm run dev
```

## 📋 The Rules

Survive 7 escalating waves. Melee enemies swing axes inside the house; shooters cover you from the street. Use cover. Some of them talk to each other — get spotted by one, and the rest come running.

Six notes are hidden across the map. Find them all to understand what this street really is.

## 🩸 A Warning

This is a solo, code-only project — every asset is procedural, not hand-modeled or recorded. It won't look like a AAA release, and it isn't trying to. What it *is*: a fully playable, atmospheric horror shooter that runs in a browser tab, built from nothing but geometry, shaders, and math.
